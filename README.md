# Обычный день фотографа

Браузерная игра про Оксану, парк и три минуты на лучшие кадры. Лови удачные моменты, наводи фокус, собирай бонусы и обходи помехи. На финальном этапе наступают сумерки: загораются фонари, у Оксаны появляется фонарик.

Игра использует Three.js и работает как статический сайт. Все библиотеки, звуки и шрифты находятся в проекте; внешние API, ключи и установка зависимостей не нужны. Если WebGL недоступен, включается резервная отрисовка на Canvas.

## Запустить на компьютере

Нужен Node.js 22 или новее. Открой терминал в папке с этим README и выполни:

```sh
npm start
```

Открой **http://127.0.0.1:8000** в браузере. Остановка сервера — `Ctrl+C`.

Не открывай `dist/index.html` двойным кликом: браузер может заблокировать загрузку звуков через `file://`.

Альтернатива с Python, без Node.js:

```sh
python -m http.server 8000 --directory dist --bind 127.0.0.1
```

На macOS/Linux команда может называться `python3`.

## Опубликовать на GitHub Pages

1. Создай репозиторий с основной веткой `main`. Для GitHub Free используй публичный репозиторий.
2. Загрузи **содержимое папки `photographer-day`**, включая `.github`, в корень репозитория. ZIP загружать не нужно: GitHub не распаковывает его в проект.
3. Открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Во вкладке **Actions** открой **Check and publish game** и нажми **Run workflow**. Если первый автоматический запуск завершился до включения Pages, запусти его заново.
5. После успешного выполнения адрес игры появится в **Settings → Pages** и в результате публикации.

Следующие изменения в `main` или `master` автоматически проходят проверки и публикуются. Workflow загружает только папку `dist`; исходные проверки и документация остаются в репозитории.

Подробная инструкция через браузер и Git: [docs/GITHUB.md](docs/GITHUB.md).

## Управление

- **WASD / стрелки** — ходить.
- **Мышь** — наводить рамку; **ЛКМ** — фотографировать.
- **Удерживать ПКМ** — фокусироваться.
- **Пробел** — пауза и правила; **Enter** — начать или повторить съёмку.
- **M / N** — звук / музыка.
- **На телефоне**: горизонтальная ориентация; слева джойстик, справа рамка. Удержание — фокус, отпускание — снимок.

Звук включается после первого действия игрока. Рекорды и достижения сохраняются в браузере отдельно для каждого адреса сайта; при переезде на новый домен прежний рекорд автоматически не переносится.

## Структура

| Путь | Содержимое |
| --- | --- |
| `dist/` | Готовая игра: HTML, JavaScript, стили и ресурсы |
| `dist/game.js`, `dist/systems.js` | Механики, этапы, погода и расписание |
| `dist/scene3d.js`, `dist/evening.js` | 3D-модели, анимация и освещение |
| `dist/ui.js`, `dist/runtime.js` | Интерфейс, запуск и адаптация окна |
| `checks/` | Проверки игры; `original/` — исходная версия для сравнения |
| `scripts/serve.mjs` | Локальный сервер без зависимостей |
| `.github/workflows/pages.yml` | Проверка и публикация через GitHub Pages |

## Проверки

```sh
npm test
```

Проверяются очки, фокус, бонусы, полная съёмка, столкновения, караван, модели, звуковые события, турист и вечернее освещение. Проверки используют модель браузерного окружения; они не заменяют визуальную проверку и прослушивание в браузере.

Архитектура и детали: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
